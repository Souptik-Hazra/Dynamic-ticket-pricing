## 🛠️ Getting Started

1.  **Clone the Repo**
2.  **Install Monolith Dependencies**:
    ```bash
    cd modular-monolith && npm install
    ```
3.  **Launch the Platform**:
    ```bash
    npm start
    ```
    *This command launches the React frontend, the Node.js API, and the Python AI sidecar concurrently.*

4.  **Admin Login**: Access the **🛡️ Market Security** tab to view the live Federated Pulse.
